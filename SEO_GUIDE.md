# SEO Gids voor AI Examentrainer

## ✅ Wat is al geïmplementeerd

### 1. Meta Tags
- **Title tag**: Optimaal (50-60 karakters)
- **Description**: Aantrekkelijk en informatief (150-160 karakters)
- **Keywords**: Relevante zoektermen
- **Open Graph tags**: Voor social media sharing
- **Twitter Cards**: Voor betere Twitter previews
- **Canonical URL**: Voorkomt duplicate content

### 2. Structured Data (JSON-LD)
- Schema.org markup voor EducationalOrganization
- Helpt Google je content beter te begrijpen
- Verhoogt kans op rich snippets in zoekresultaten

### 3. Technical SEO
- ✅ Sitemap.xml - Voor snelle indexering
- ✅ Robots.txt - Vertelt zoekmachines wat te crawlen
- ✅ Mobile-friendly viewport meta tag
- ✅ UTF-8 charset
- ✅ Language tag (nl)

## 🚀 Volgende stappen om vindbaar te worden

### Stap 1: Google Search Console Setup
1. Ga naar [Google Search Console](https://search.google.com/search-console)
2. Klik op "Add Property"
3. Voeg je URL toe: `https://ai-examentrainer.vercel.app`
4. Verifieer eigendom via HTML tag of DNS
5. Submit je sitemap: `https://ai-examentrainer.vercel.app/sitemap.xml`

### Stap 2: Google Analytics 4 (Optioneel)
Je hebt al Vercel Analytics, maar voor extra inzichten:
1. Ga naar [Google Analytics](https://analytics.google.com)
2. Maak een nieuwe property aan
3. Voeg tracking code toe aan je site
4. Track conversies en user behavior

### Stap 6: Performance Optimalisatie
Google houdt van snelle websites:

- ✅ Vercel hosting (al snel)
- ✅ Image optimization (Supabase Storage)
- 🔄 **Nog te doen:**
  - Lazy loading voor afbeeldingen
  - Code splitting
  - Minimize CSS/JS
  - Use CDN (al via Vercel)

## 📊 KPI's om te Tracken

### Google Search Console:
- **Impressions**: Hoe vaak je verschijnt in zoekresultaten
- **Clicks**: Hoeveel mensen klikken
- **CTR (Click-Through Rate)**: Clicks / Impressions
- **Average Position**: Gemiddelde ranking positie
- **Core Web Vitals**: Performance metrics

### Doelen:
- Maand 1: 100+ impressions
- Maand 2: 500+ impressions, 50+ clicks
- Maand 3: 2000+ impressions, 200+ clicks
- Maand 6: Top 10 voor "eindexamen oefenen"

## 🚨 Veelvoorkomende Fouten

### Vermijd deze:
- ❌ Keyword stuffing (te vaak hetzelfde woord)
- ❌ Duplicate content
- ❌ Broken links
- ❌ Slow page speed
- ❌ No mobile optimization
- ❌ Missing alt text op afbeeldingen
- ❌ Thin content (te weinig tekst)
